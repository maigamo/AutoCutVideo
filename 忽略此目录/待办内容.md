🔁 二、核心任务流转流程（Task Flow）
🧱 1️⃣ 视频下载任务流程
[用户输入视频链接或导入文件]
        ↓
[UI 层提交任务 → Controller 创建任务记录]
        ↓
[Task Manager 将任务分配给 下载 Worker]
        ↓
[下载 Worker 调用 Playwright]
   - 打开 tikvid.io / ssstik.io / 目标网站
   - 填入视频链接
   - 点击下载按钮
   - 捕获下载事件，保存视频
        ↓
[下载完成 → 回写任务状态 “Downloaded”]
        ↓
[Event Bus 通知 UI → 更新任务进度]

✂️ 2️⃣ 视频自动剪辑任务流程
[任务状态 = “Downloaded”]
        ↓
[用户手动触发 或 系统自动检测开始剪辑]
        ↓
[Task Manager 分配任务到 剪辑 Worker]
        ↓
[剪辑 Worker 执行处理逻辑]
   - 调用 MoviePy / FFmpeg
   - 自动识别片段（可配置规则：截取前10秒、删除水印区域、添加Logo等）
   - 保存输出视频到 Edited 目录
        ↓
[任务状态更新为 “Edited”]
        ↓
[Event Bus 通知 UI → 预览剪辑效果]

📦 3️⃣ 导出 / 删除任务流程
[用户在 UI 选择视频 → 点击导出 / 删除]
        ↓
[Task Manager 创建 Export 任务]
        ↓
[Export Worker 执行文件操作]
   - 批量压缩视频为 zip
   - 或执行删除
   - 或调用 MCP 发布 API
        ↓
[任务状态 → “Exported” / “Deleted”]
        ↓
[Event Bus 通知 UI 层刷新]

🤖 4️⃣ 自动发布流程（可选扩展）
[任务状态 = “Edited”]
        ↓
[触发 MCP Agent（如自动发布抖音/B站）]
        ↓
[Agent 上传视频 / 自动填写标题标签]
        ↓
[返回发布结果 → 更新状态 “Published”]

🧠 三、逻辑与模块关系说明
模块	功能说明	技术建议
UI 层	提供用户交互：输入视频、查看任务、预览剪辑	Electron（桌面）或 Vue3 + Naive UI（Web）
Task Manager	控制任务生命周期，分配给对应 Worker	Python（FastAPI + Celery）或 Node（BullMQ）
下载 Worker	使用 Playwright 控制网站执行下载	Python 或 Node 均可（Python 稳定）
剪辑 Worker	调用 FFmpeg / MoviePy 实现自动剪辑	Python（moviepy/ffmpeg-python）
导出 Worker	负责导出、删除、发布操作	Python 文件系统操作
存储层	保存文件、任务、配置、日志	SQLite + 本地文件目录（简单稳定）
Event Bus	用于实时任务更新	WebSocket / IPC / Redis PubSub
