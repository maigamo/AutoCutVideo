### 2. 修改getActualPath方法 - 自动创建目录

**修改前**：
```typescript
getActualPath(pathType): string {
  const paths = this.get('paths')
  const customKey = `custom${...}` as keyof AppConfig['paths']
  return (paths[customKey] as string) || paths[pathType]
}
```

**修改后**：
```typescript
getActualPath(pathType): string {
  const paths = this.get('paths')
  const customKey = `custom${...}` as keyof AppConfig['paths']
  const actualPath = (paths[customKey] as string) || paths[pathType]
  
  // ✅ 确保目录存在
  if (!fs.existsSync(actualPath)) {
    try {
      fs.mkdirSync(actualPath, { recursive: true })
      logger.debug('已自动创建目录', { module: 'config', path: actualPath })
    } catch (error) {
      logger.error('创建目录失败', { module: 'config', path: actualPath, error })
    }
  }
  
  return actualPath
}
```

**效果**：
- ✅ 每次获取路径时自动检查目录是否存在
- ✅ 不存在则自动创建（递归创建父目录）
- ✅ 避免文件保存时报"目录不存在"错误

## 维护建议

### 1. 添加新路径时
```typescript
// 1. 在 ConfigService 的 AppConfig 接口中定义
interface AppConfig {
  paths: {
    newDir: string           // 默认路径
    customNewDir?: string    // 自定义路径（可选）
  }
}

// 2. 在 defaultConfig 中设置默认值
const defaultConfig = {
  paths: {
    newDir: path.join(projectRoot, 'new-folder')
  }
}

// 3. 在 ensureDefaultDirectories 中添加
this.defaultPaths.newDir

// 4. 使用时调用 getActualPath

```

### 2. 路径规范
- ✅ 使用 `path.join()` 而不是字符串拼接
- ✅ 使用 `path.dirname()` 获取父目录
- ✅ 使用 `fs.mkdirSync(path, { recursive: true })` 创建目录
- ✅ 使用 `fs.existsSync()` 检查是否存在
