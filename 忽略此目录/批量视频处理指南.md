# AutoCutVideo 批量视频自动化处理指南

本指南介绍如何使用批量处理脚本实现视频的自动化处理。

---

## 🎯 功能特性

批量处理脚本支持以下自动化操作：

- ✂️ **批量处理**：一次处理多个视频文件
- 🎬 **1.2 倍速**：自动调整播放速度
- 🔄 **左右翻转**：镜像翻转视频
- ✨ **锐化 10%**：增强画面清晰度
- 🔇 **原音频静音**：移除原始视频声音
- 🎵 **随机背景音乐**：从音乐库中随机选择并自动裁剪匹配视频长度
- 💾 **高质量导出**：CRF 18 高质量 H.264 编码
- 📝 **智能命名**：原文件名 + 时间戳

## 📋 前置要求

### 必需软件

1. **FFmpeg** - 视频处理引擎
2. **Node.js** - 运行脚本环境

### 安装 FFmpeg

#### Windows

**方法 1：使用 Chocolatey（推荐）**
```powershell
choco install ffmpeg
```

**方法 2：手动安装**
1. 下载：https://github.com/BtbN/FFmpeg-Builds/releases
2. 解压到 `C:\ffmpeg`
3. 添加到系统 PATH：`C:\ffmpeg\bin`

#### Mac

```bash
# 使用 Homebrew
brew install ffmpeg
```

#### Linux

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install ffmpeg

# CentOS/RHEL
sudo yum install ffmpeg
```

### 验证安装

```bash
ffmpeg -version
ffprobe -version
node --version
```

## 🚀 使用方法

### 第一步：准备文件结构

创建以下目录结构：

```
AutoCutVideo/
├── scripts/
│   └── batch-video-processor.js  # 处理脚本（已创建）
├── videos/
│   ├── input/                    # 放入待处理的视频
│   │   ├── video1.mp4
│   │   ├── video2.mp4
│   │   └── video3.mov
│   └── output/                   # 输出目录（自动创建）
└── music/                        # 背景音乐库
    ├── bgm1.mp3
    ├── bgm2.mp3
    └── bgm3.wav
```

### 第二步：准备素材

1. **放入待处理视频**：
   - 将视频文件放入 `videos/input/` 目录
   - 支持格式：`.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`

2. **准备背景音乐**：
   - 将音乐文件放入 `music/` 目录
   - 支持格式：`.mp3`, `.wav`, `.aac`, `.m4a`, `.flac`

### 第三步：运行脚本

```bash
# 进入项目根目录
cd AutoCutVideo

# 运行批量处理
node scripts/batch-video-processor.js videos/input videos/output music
```

### 命令格式

```bash
node scripts/batch-video-processor.js <输入目录> <输出目录> <音乐目录>
```

**参数说明**：
- `<输入目录>`：待处理视频所在目录
- `<输出目录>`：处理后视频的保存目录
- `<音乐目录>`：背景音乐库目录

## ⚙️ 自定义配置

### 修改处理参数

编辑 `scripts/batch-video-processor.js` 中的 `CONFIG` 对象：

```javascript
const CONFIG = {
  // 视频处理参数
  SPEED_RATE: 1.5,              // 改为 1.5 倍速
  SHARPEN_AMOUNT: 0.2,          // 改为 20% 锐化
  
  // 编码质量（CRF 值越小质量越高，文件越大）
  CRF: '18',                    // 18 = 高质量（推荐）
                                // 23 = 默认质量
                                // 28 = 中等质量
  
  // 视频码率
  VIDEO_BITRATE: '8000k',       // 8Mbps（高质量）
                                // '5000k' = 中等质量
                                // '3000k' = 较低质量
  
  // 编码速度
  PRESET: 'slow',               // slow = 慢但质量好
                                // medium = 平衡
                                // fast = 快但质量略低
};
```

### 添加更多视频特效

在 `filter_complex` 中添加滤镜：

```javascript
'-filter_complex', [
  `[0:v]setpts=PTS/${CONFIG.SPEED_RATE}`,
  'hflip',
  `unsharp=5:5:${CONFIG.SHARPEN_AMOUNT}:5:5:0`,
  
  // 添加更多特效
  'eq=contrast=1.1:brightness=0.05',    // 对比度 +10%，亮度 +5%
  'hue=s=1.2',                          // 饱和度 +20%
  'noise=alls=10:allf=t',               // 添加轻微噪点（胶片感）
].join(',') + '[v]',
```

### 常用 FFmpeg 滤镜

```javascript
// 画面调整
'eq=contrast=1.1'                    // 对比度
'eq=brightness=0.1'                  // 亮度
'eq=saturation=1.2'                  // 饱和度
'hue=s=1.1'                          // 色调饱和度

// 画面特效
'unsharp=5:5:1.0:5:5:0'             // 锐化
'boxblur=2:1'                        // 模糊
'noise=alls=20:allf=t'               // 噪点

// 颜色调整
'colorbalance=rs=0.1:gs=0:bs=-0.1'  // 色彩平衡
'curves=vintage'                     // 复古色调
'eq=gamma=1.2'                       // 伽马值

// 画面变换
'hflip'                              // 水平翻转
'vflip'                              // 垂直翻转
'rotate=PI/4'                        // 旋转 45 度
'crop=iw*0.8:ih*0.8'                // 裁剪

// 缩放
'scale=1920:1080'                    // 缩放到 1080p
'scale=iw*0.5:ih*0.5'               // 缩小到 50%
```

## 🔧 故障排查

### 问题 1：找不到 FFmpeg

**错误**：
```
FFmpeg 启动失败: spawn ffmpeg ENOENT
```

**解决方案**：
1. 确认已安装 FFmpeg：`ffmpeg -version`
2. 确认 FFmpeg 在系统 PATH 中
3. Windows 用户：重启终端或重启电脑

### 问题 2：处理速度很慢

**原因**：`PRESET: 'slow'` 追求质量牺牲速度

**解决方案**：
```javascript
// 修改为更快的预设
PRESET: 'medium',  // 或 'fast'
```

### 问题 3：输出文件太大

**解决方案**：
```javascript
// 降低质量参数
CRF: '23',              // 从 18 提高到 23
VIDEO_BITRATE: '5000k', // 从 8000k 降低到 5000k
```

### 问题 4：音频不匹配

**症状**：视频和音频不同步

**解决方案**：
- 确保音乐文件格式正确（推荐 MP3）
- 检查音乐文件是否损坏
- 使用 `-async 1` 参数强制音频同步：

```javascript
args.push('-async', '1');
```

### 问题 5：内存不足

**症状**：处理大文件时崩溃

**解决方案**：
1. 一次处理少量文件
2. 降低输出质量
3. 添加两遍编码（更省内存）

for (let i = 0; i < videoFiles.length; i += concurrency) {
  chunks.push(videoFiles.slice(i, i + concurrency));
}

for (const chunk of chunks) {

}

## 🆚 方案对比

### 方案 1：FFmpeg CLI 脚本（推荐）⭐⭐⭐⭐⭐

**优点**：
- ✅ 性能最优（原生二进制）
- ✅ 代码简单（~200 行）
- ✅ 易于维护
- ✅ 支持硬件加速
- ✅ 适合批量自动化

**缺点**：
- ❌ 需要安装 FFmpeg

**适用场景**：
- 批量自动化处理
