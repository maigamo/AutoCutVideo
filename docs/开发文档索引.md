## 🎯 项目定位（必读）

### 这是一个什么项目？

**AutoCutVideo = 批量视频自动剪辑工具**

用户只需：
1. 📝 配置一次剪辑参数（倍速、翻转、锐化、背景音乐等）
2. 📋 粘贴多个视频链接
3. ▶️ 点击开始，自动完成：下载 → 剪辑 → 生成结果
4. ✅ 查看原视频和剪辑后视频，选择需要的导出

### 核心用户流程

```
步骤1：批量输入页面
  ├─ 配置自动剪辑参数（一次配置，批量应用）
  ├─ 上传音频文件到音乐素材库（可选）
  ├─ 粘贴多个URL链接
  └─ 点击"开始处理" → 创建一个批次任务

步骤2：自动处理（后台）
  ├─ 下载所有视频
  ├─ 自动剪辑（应用配置的参数）
  └─ 生成剪辑后视频

步骤3：视频管理页面
  ├─ 查看批次任务进度
  ├─ 对比查看原视频 vs 剪辑后视频
  └─ 选择需要的视频

步骤4：导出下载页面
  ├─ 批量导出选中的视频
  ├─ 可选压缩为ZIP
  └─ 可选删除源文件释放空间
```

### 关键概念

**批次任务（Batch Task）**：
- 一次提交的多个URL链接 = 一个批次任务
- 每个批次任务有独立的ID、创建时间、处理进度
- 批次内的所有视频使用相同的剪辑参数

**音频素材库**：
- 用户可上传多个音频文件（MP3/WAV/M4A）
- 存储在独立的目录（`music/`）
- 支持两种使用模式：
  - 随机选择：每个视频随机选一首背景音乐
  - 顺序遍历：按上传顺序依次使用
- 可以管理音频文件：查看列表、删除、重新上传

### 场景4：实现批次任务管理

**需要阅读：**
1. [项目需求文档](./项目需求文档.md) → 任务调度层
2. [项目需求文档](./项目需求文档.md) → 核心流程设计

**关键概念：**
- 一个批次任务 = 一次提交的多个URL链接
- 批次任务包含多个下载任务和剪辑任务
- 批次任务有整体进度和状态

**数据库设计：**
```sql
-- 批次任务表（新增）
CREATE TABLE batch_tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT,                        -- 任务名称（可选，用户输入）
  status TEXT NOT NULL,             -- pending/processing/completed/failed
  total_videos INTEGER DEFAULT 0,   -- 总视频数
  completed_videos INTEGER DEFAULT 0, -- 已完成视频数
  edit_config TEXT,                 -- 剪辑配置（JSON）
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  completed_at DATETIME
);

-- 任务表（增加batch_id字段）
CREATE TABLE tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  batch_id INTEGER,                 -- 所属批次任务ID
  type TEXT NOT NULL,               -- 'download' | 'edit'
  status TEXT NOT NULL,
  url TEXT,
  ...
  FOREIGN KEY (batch_id) REFERENCES batch_tasks(id)
);
```

**实现流程：**
```javascript
// 1. 创建批次任务
const batchTask = await db.insert('batch_tasks', {
  name: '批次任务-2025-11-13',
  status: 'pending',
  total_videos: urls.length,
  edit_config: JSON.stringify(editConfig)
});

// 2. 为每个URL创建下载任务
for (const url of urls) {
  await db.insert('tasks', {
    batch_id: batchTask.id,
    type: 'download',
    url: url,
    status: 'pending'
  });
}

// 3. 开始处理
await taskManager.startBatchTask(batchTask.id);
```
