## 方案概述

### 当前系统能力

**AutoCutVideo** 是一个基于 FFmpeg 的命令行视频批量处理工具，具备以下功能：

- ⚡ 视频倍速处理（1.2x）
- 🔄 左右翻转
- ✨ 智能锐化（10%）
- 🎵 背景音乐替换（原音频静音）
- 🎯 高质量导出（H.264 CRF 18）

**当前资源占用**：
- **CPU**: 单视频处理占用 1-4 核（取决于编码器和预设）
- **内存**: 约 500MB - 2GB（取决于视频分辨率）
- **磁盘 I/O**: 中等（读取输入 + 写入输出）
- **处理速度**: 1 分钟 1080p 视频约需 3-5 分钟（`preset=slow`）

---

### 目标系统能力

将系统改造为 **Web 视频处理服务平台**，提供：

1. **📤 视频链接上传**
   - 支持主流视频平台链接（YouTube、抖音、快手、B站等）
   - 自动解析视频元数据
   - 批量链接上传

2. **📥 自动下载与分类**
   - 智能识别视频来源平台
   - 按平台、时间、标签自动分类
   - 下载队列管理

3. **✂️ 自动化剪辑处理**
   - 应用预设的剪辑模板
   - 支持自定义剪辑参数
   - 批量处理队列

4. **📦 处理结果分发**
   - 在线预览

   - 批量打包下载
   - CDN 加速（可选）

5. **🎛️ Web 管理界面**

## 核心功能模块

### 1. 链接解析模块 (Link Parser)

**功能**:
- 识别视频平台（YouTube、抖音、快手、B站、西瓜视频等）
- 提取视频 ID 和元数据
- 验证链接有效性

**技术实现**:
```javascript
// 使用 yt-dlp 作为通用下载器
import { execFile } from 'child_process';
import { promisify } from 'util';

const execFileAsync = promisify(execFile);

async function parseVideoLink(url) {
  // 使用 yt-dlp --dump-json 获取元数据
  const { stdout } = await execFileAsync('yt-dlp', [
    '--dump-json',
    '--no-download',
    url
  ]);
  
  const metadata = JSON.parse(stdout);
  return {
    platform: metadata.extractor,
    videoId: metadata.id,
    title: metadata.title,
    duration: metadata.duration,
    thumbnail: metadata.thumbnail,
    uploader: metadata.uploader,
  };
}
```

**依赖**:
- `yt-dlp` (支持 1000+ 网站的通用下载器)
- 正则表达式库用于 URL 验证

### 2. 下载管理模块 (Download Manager)

**功能**:
- 视频下载队列管理
- 断点续传
- 下载速度控制
- 并发下载管理

**技术实现**:
```javascript
import Queue from 'bull'; // Redis 任务队列

// 创建下载队列
const downloadQueue = new Queue('video-download', {
  redis: { host: 'localhost', port: 6379 }
});

// 添加下载任务
async function addDownloadTask(videoInfo) {
  return downloadQueue.add({
    url: videoInfo.url,
    videoId: videoInfo.videoId,
    platform: videoInfo.platform,
    outputPath: `/storage/raw/${videoInfo.videoId}.mp4`,
  }, {
    attempts: 3, // 重试次数
    backoff: { type: 'exponential', delay: 5000 },
  });
}

// Worker 处理下载任务
downloadQueue.process(async (job) => {
  const { url, outputPath } = job.data;
  
  // 使用 yt-dlp 下载
  await execFileAsync('yt-dlp', [
    '-f', 'bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]',
    '-o', outputPath,
    '--progress',
    url
  ]);
  
  return { success: true, path: outputPath };
});
```

**依赖**:
- `yt-dlp` (视频下载)
- `bull` (任务队列)
- `redis` (队列存储)

### 3. 自动分类模块 (Auto Classifier)

**功能**:
- 按视频平台分类
- 按上传时间分类
- 按标签/关键词分类
- 自定义分类规则

**技术实现**:
```javascript
async function classifyVideo(videoMetadata) {
  const classification = {
    platform: videoMetadata.platform, // 抖音、快手、B站等
    uploadDate: new Date(videoMetadata.upload_date).toISOString().split('T')[0],
    category: videoMetadata.categories?.[0] || 'uncategorized',
    tags: videoMetadata.tags || [],
  };
  
  // 保存到数据库
  await db.videos.update({
    where: { id: videoMetadata.videoId },
    data: { classification }
  });
  
  // 创建物理分类目录
  const categoryPath = `/storage/classified/${classification.platform}/${classification.uploadDate}`;
  await fs.mkdir(categoryPath, { recursive: true });
  
  return classification;
}
```

**数据库表设计**:
```sql
CREATE TABLE video_classifications (
  id SERIAL PRIMARY KEY,
  video_id VARCHAR(255) UNIQUE NOT NULL,
  platform VARCHAR(50) NOT NULL,
  category VARCHAR(100),
  upload_date DATE,
  tags TEXT[],
  created_at TIMESTAMP DEFAULT NOW(),
  INDEX idx_platform (platform),
  INDEX idx_category (category),
  INDEX idx_upload_date (upload_date)
);
```

### 4. 视频剪辑模块 (Video Editor)

**功能**:
- 应用剪辑模板（倍速、翻转、锐化、背景音乐）
- 支持自定义参数
- 批量处理
- 进度追踪

**技术实现** (基于现有的 `batch-video-processor.js`):
```javascript
import Queue from 'bull';

const editQueue = new Queue('video-edit', {
  redis: { host: 'localhost', port: 6379 }
});

// 添加剪辑任务
async function addEditTask(videoId, template = 'default') {
  const video = await db.videos.findOne({ where: { id: videoId } });
  
  return editQueue.add({
    videoId,
    inputPath: video.rawPath,
    outputPath: `/storage/edited/${videoId}_edited.mp4`,
    template, // 剪辑模板：default, fast, slow, custom
    musicPath: await getRandomMusic('/storage/music'),
  }, {
    attempts: 2,
    timeout: 3600000, // 1 小时超时
  });
}

// Worker 处理剪辑任务
editQueue.process(async (job, done) => {
  const { inputPath, outputPath, musicPath, template } = job.data;
  
  // 复用现有的 processVideo 函数
  const config = getTemplateConfig(template);
  
  await processVideo({
    inputPath,
    outputPath,
    musicPath,
    config,
    onProgress: (percent) => {
      job.progress(percent);
    }
  });
  
  done(null, { success: true, outputPath });
});
```

**剪辑模板配置**:

### 5. 任务调度模块 (Task Scheduler)

**功能**:
- 任务优先级管理
- 资源分配
- 任务重试机制
- 失败任务告警

**技术实现**:
```javascript
import { Queue, QueueScheduler } from 'bull';

// 任务调度器
const scheduler = new QueueScheduler('video-processing');

// 创建任务链
async function createProcessingPipeline(videoUrl) {
  // 1. 解析链接
  const metadata = await parseVideoLink(videoUrl);
  
  // 2. 保存到数据库
  const video = await db.videos.create({
    data: {
      url: videoUrl,
      videoId: metadata.videoId,
      title: metadata.title,
      platform: metadata.platform,
      status: 'pending',
    }
  });
  
  // 3. 添加下载任务
  const downloadJob = await downloadQueue.add({
    videoId: video.id,
    url: videoUrl,
  }, { priority: 1 });
  
  // 4. 下载完成后触发分类和剪辑
  downloadJob.finished().then(async (result) => {
    // 分类
    await classifyVideo({ videoId: video.id, ...metadata });
    
    // 添加剪辑任务
    await editQueue.add({
      videoId: video.id,
      inputPath: result.path,
    }, { priority: 2 });
  });
  
  return video;
}
```

```javascript
import { Server } from 'socket.io';

const io = new Server(httpServer, {
  cors: { origin: '*' }
});

io.on('connection', (socket) => {
  console.log('Client connected:', socket.id);
  
  // 客户端订阅任务进度
  socket.on('subscribe', (taskId) => {
    socket.join(`task-${taskId}`);
  });
});

// 在 Worker 中推送进度
downloadQueue.on('progress', (job, progress) => {
  io.to(`task-${job.data.taskId}`).emit('progress', {
    taskId: job.data.taskId,
    stage: 'downloading',
    progress: progress,
  });
});

editQueue.on('progress', (job, progress) => {
  io.to(`task-${job.data.taskId}`).emit('progress', {
    taskId: job.data.taskId,
    stage: 'editing',

- CPU 占用降低 70%

- 使用流式处理
- 及时清理临时文件

// FFmpeg 内存限制
'-max_memory', '2G',
```

- 定期清理过期文件
- 压缩历史视频
- 使用对象存储 (S3/OSS)
- 冷热数据分层存储

#### 4. 网络优化

- 使用 CDN 加速下载

## 安全性考虑

### 1. 认证与授权

- **JWT Token**: 无状态认证
- **API Key**: 服务间调用
- **OAuth 2.0**: 第三方登录 (可选)
- **RBAC**: 基于角色的权限控制

### 2. 数据安全

- **传输加密**: HTTPS (TLS 1.3)
- **存储加密**: 数据库加密、文件加密
- **密码加密**: bcrypt/argon2
- **敏感信息**: 使用环境变量或密钥管理服务

### 3. 输入验证

- **URL 白名单**: 限制可下载的域名
- **文件类型检查**: 验证视频格式
- **文件大小限制**: 防止资源耗尽
- **SQL 注入防护**: 使用 ORM 参数化查询
- **XSS 防护**: 前端输入清理

### 4. 速率限制

```javascript
import rateLimit from 'express-rate-limit';

const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 分钟
  max: 100, // 最多 100 个请求
  message: '请求过于频繁，请稍后再试'
});

app.use('/api/', apiLimiter);
```

### 5. 防止滥用

- **用户配额**: 限制每日处理数量
- **文件大小限制**: 单视频最大 500MB
- **时长限制**: 单视频最长 30 分钟
- **验证码**: 防止自动化脚本

### 6. 日志审计

- 记录所有 API 请求
- 记录视频处理日志
- 异常告警
- 定期安全审计

## 总结与建议

### 优势分析

✅ **复用现有代码**: 核心剪辑逻辑可直接使用  
✅ **技术成熟**: 技术栈稳定可靠  
✅ **扩展性好**: 架构支持水平扩展  
✅ **成本可控**: 从小规模开始，按需扩展  

### 挑战分析

⚠️ **版权风险**: 需要明确用户协议  
⚠️ **成本管理**: 大规模运营成本较高  
⚠️ **技术复杂度**: 分布式系统需要一定运维能力  
⚠️ **资源消耗**: 视频处理占用大量 CPU 和存储  

### 建议

#### 短期建议 (3 个月内)

1. **从 MVP 开始**: 先验证核心功能和市场需求
2. **小规模部署**: 单服务器部署,成本 ¥500-1500/月
3. **快速迭代**: 根据用户反馈快速优化
4. **成本控制**: 设置用户配额,避免滥用

#### 中期建议 (3-12 个月)

1. **优化性能**: 引入硬件加速、CDN
2. **扩展功能**: 支持更多平台、更多剪辑功能
3. **商业化**: 制定收费策略 (免费层 + 付费层)
4. **团队建设**: 招募专职开发、运维人员

#### 长期建议 (12 个月+)

1. **规模化部署**: Kubernetes 集群、多地域部署
2. **AI 功能**: 智能剪辑、自动字幕、内容识别
3. **开放 API**: 允许第三方集成
4. **国际化**: 支持多语言、多地域
