# AutoCutVideo Electron 桌面应用 - 项目需求文档

## 📋 项目概述

### 项目背景
本项目旨在开发一款基于 Electron 的桌面应用，实现**视频链接批量下载 → 自动剪辑 → 可视化管理 → 批量导出/发布**的完整工作流。用户可以通过输入多个视频平台链接（抖音、小红书、Twitter等），自动下载视频并进行智能剪辑处理，最终通过可视化界面管理和导出处理后的视频。

### 核心价值
- ✅ **一站式解决方案**：从下载到剪辑到导出，全流程自动化
- ✅ **多平台支持**：支持抖音、小红书、Twitter、YouTube等主流平台
- ✅ **智能剪辑**：自动应用倍速、翻转、锐化、背景音乐等效果
- ✅ **可视化管理**：直观的任务管理和视频预览界面
- ✅ **批量处理**：支持批量下载、批量剪辑、批量导出
- ✅ **可扩展性**：预留 MCP 集成接口，支持自动发布功能

### 2. 任务调度层（Controller）

#### 2.1 任务管理器（Task Manager）
**职责：**
- 创建任务记录（下载/剪辑/导出）
- 任务状态管理（Pending/Running/Completed/Failed/Cancelled）
- 任务优先级排序
- 任务队列调度（FIFO/优先级）
- 并发控制（限制同时执行的任务数）
- 任务依赖管理（下载完成后自动触发剪辑）

**状态流转：**
```
Pending → Downloading → Downloaded → Editing → Edited → Exporting → Exported → (Published)
                ↓           ↓           ↓          ↓
              Failed      Failed      Failed    Failed
                ↓           ↓           ↓          ↓
              Retry       Retry       Retry     Retry
```

#### 2.2 事件总线（Event Bus）
**功能：**
- 广播任务状态变更事件
- 通知 UI 层更新（通过 IPC）
- 进度事件推送（实时进度条更新）
- 错误事件处理
- 日志事件收集

**事件类型：**
- `task:created` - 任务创建
- `task:started` - 任务开始
- `task:progress` - 任务进度更新
- `task:completed` - 任务完成
- `task:failed` - 任务失败
- `task:cancelled` - 任务取消
- `download:started` - 下载开始
- `download:progress` - 下载进度
- `edit:started` - 剪辑开始
- `edit:progress` - 剪辑进度

### 3. 执行层（Workers）

#### 3.1 下载 Worker
**技术方案：**
- 使用 Playwright 自动化控制浏览器
- 支持多平台下载网站：
  - ssstik.li（抖音）
  - godownloader.app（通用）
  - xdown.app（Twitter）
  - savefrom.net（YouTube）

**工作流程：**
1. 解析视频链接，识别平台类型
2. 根据平台选择对应的下载网站
3. 启动无头浏览器（Headless Chrome）
4. 自动填入链接并点击下载按钮
5. 监听下载事件，保存文件到指定目录
6. 返回下载结果（文件路径/错误信息）

**容错机制：**
- 失败自动重试（最多3次）
- 切换备用下载网站
- 超时检测（60秒）
- 代理切换（如配置）

#### 3.2 剪辑 Worker
**技术方案：**
- 使用 FFmpeg 命令行工具
- 基于 fluent-ffmpeg 库封装（Node.js）

**处理能力：**
- ✅ 倍速调节（setpts）
- ✅ 镜像翻转（hflip/vflip）
- ✅ 锐化处理（unsharp）
- ✅ 音频替换（静音原音 + 添加背景音乐）
- ✅ 视频裁剪（trim）
- ✅ 水印添加（overlay）
- ✅ 字幕嵌入（subtitles）
- ✅ 画质调节（亮度/对比度/饱和度）
- ✅ 分辨率转换（scale）

**参考现有实现：**
参考 `scripts/batch-video-processor.js` 的处理逻辑：
- 1.2倍速：`setpts=PTS/1.2`
- 左右翻转：`hflip`
- 锐化10%：`unsharp=5:5:0.1:5:5:0`
- 音频处理：静音原音 + 裁剪背景音乐到视频长度

**性能优化：**
- 硬件加速支持（h264_nvenc/h264_qsv/h264_amf）
- 多线程编码
- 进度回调（每秒更新）

#### 3.3 导出 Worker
**功能：**
- 文件批量复制/移动
- ZIP 压缩打包
- 文件重命名（按规则）
- 临时文件清理
- 发布 API 调用（MCP 集成）

#### 4.2 任务数据库
**技术选型：** SQLite
**数据表设计：**

**batch_tasks 表：**（新增）
```sql
CREATE TABLE batch_tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT,                        -- 任务名称（用户输入或自动生成）
  status TEXT NOT NULL,             -- 'pending' | 'processing' | 'completed' | 'failed'
  total_videos INTEGER DEFAULT 0,   -- 总视频数
  completed_videos INTEGER DEFAULT 0, -- 已完成视频数
  failed_videos INTEGER DEFAULT 0,  -- 失败视频数
  edit_config TEXT,                 -- 剪辑配置（JSON）
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  started_at DATETIME,
  completed_at DATETIME
);
```

**tasks 表：**（增加batch_id字段）
```sql
CREATE TABLE tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  batch_id INTEGER,                -- 所属批次任务ID（新增）
  type TEXT NOT NULL,              -- 'download' | 'edit' | 'export'
  status TEXT NOT NULL,            -- 状态
  url TEXT,                        -- 原始链接（下载任务）
  platform TEXT,                   -- 平台标识
  input_path TEXT,                 -- 输入文件路径
  output_path TEXT,                -- 输出文件路径
  config TEXT,                     -- 配置（JSON）
  progress INTEGER DEFAULT 0,      -- 进度（0-100）
  error_message TEXT,              -- 错误信息
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  started_at DATETIME,
  completed_at DATETIME,
  FOREIGN KEY (batch_id) REFERENCES batch_tasks(id)
);
```

**videos 表：**
```sql
CREATE TABLE videos (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  batch_id INTEGER,                -- 所属批次任务ID（新增）
  filename TEXT NOT NULL,
  file_path TEXT NOT NULL,
  file_size INTEGER,
  duration REAL,                   -- 时长（秒）
  resolution TEXT,                 -- 分辨率（1920x1080）
  thumbnail_path TEXT,             -- 缩略图路径
  is_edited BOOLEAN DEFAULT 0,     -- 是否已剪辑
  source_task_id INTEGER,          -- 关联的下载任务 ID
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (batch_id) REFERENCES batch_tasks(id),
  FOREIGN KEY (source_task_id) REFERENCES tasks(id)
);
```

**audio_materials 表：**（新增）
```sql
CREATE TABLE audio_materials (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  filename TEXT NOT NULL,
  file_path TEXT NOT NULL,
  file_size INTEGER,
  duration REAL,                   -- 时长（秒）
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**publish_records 表：**（可选，未来扩展）
```sql
CREATE TABLE publish_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  video_id INTEGER NOT NULL,
  platform TEXT NOT NULL,
  publish_url TEXT,
  title TEXT,
  tags TEXT,
  status TEXT,
  published_at DATETIME,
  FOREIGN KEY (video_id) REFERENCES videos(id)
);
```

## 🛠️ 技术选型

### 1. 核心框架

#### Electron
- **版本：** `electron@32.2.7`（最新稳定版）
- **选择理由：**
  - 成熟稳定，社区活跃
  - 跨平台支持（Windows/macOS/Linux）
  - 强大的 Node.js 集成能力
  - 丰富的原生 API

#### Node.js
- **精确版本：** `18.20.5` (LTS)
- **选择理由：**
  - Electron 32.2.7 内置此版本
  - 原生 ESM 支持
  - 性能优化
  - 长期支持至2025年4月
- **⚠️ 重要：** 必须使用18.20.x系列，确保与Electron 32兼容

### 2. UI 框架

#### Vue 3
- **版本：** `vue@3.5.12`（最新稳定版）
- **选择理由：**
  - 组合式 API（Composition API）
  - 更好的 TypeScript 支持
  - 性能优化（Proxy 响应式）
  - 生态成熟

#### Element Plus
- **版本：** `element-plus@2.8.8`（最新稳定版）
- **选择理由：**
  - 专为 Vue 3 设计的 UI 组件库
  - 组件丰富且美观
  - 文档完善，中文支持好

- Naive UI `@2.40.1`（更轻量，设计更现代）
- Ant Design Vue `@4.2.3`（企业级设计）

### 3. 构建工具

- **选择理由：**

## 🔄 核心流程设计

### 1. 下载流程

```
用户输入链接 → UI 提交 → 主进程创建下载任务
                                    ↓
                           TaskManager 分配给 DownloadWorker
                                    ↓
                           Playwright 自动化下载
                                    ↓
                           保存文件 → 更新数据库 → 发送事件
                                    ↓
                           UI 收到事件 → 更新界面
```

### 2. 剪辑流程

```
用户选择视频 → 配置剪辑参数 → 点击开始剪辑
                                    ↓
                           主进程创建剪辑任务
                                    ↓
                           TaskManager 分配给 EditWorker
                                    ↓
                           FFmpeg 处理视频（带进度回调）
                                    ↓
                           保存输出文件 → 更新数据库 → 发送事件
                                    ↓
                           UI 收到事件 → 更新进度条 → 显示预览
```

### 3. 导出流程

```
用户选择视频 → 设置导出选项 → 点击导出
                                    ↓
                           主进程创建导出任务
                                    ↓
                           ExportWorker 执行文件操作
                                    ↓
                    复制/移动文件 → 压缩 ZIP → 清理临时文件
                                    ↓
                           更新数据库 → 发送完成事件
                                    ↓
                           UI 显示成功提示 → 打开导出目录
```

## 📝 数据库管理脚本（db-manager.js）

### 功能要求
根据项目规则，需要维护一个 `db-manager.js` 脚本，用于：
- ✅ **初始化数据库**（init）：创建表结构
- ✅ **数据迁移**（migrate）：版本升级时的表结构变更
- ✅ **清空数据**（reset）：清除所有任务和视频记录
- ✅ **数据库修复**（repair）：修复损坏的数据库

### 脚本设计概要

```javascript
#!/usr/bin/env node

/**
 * 数据库管理脚本
 * 
 * 用法：
 *   node scripts/db-manager.js init      # 初始化数据库
 *   node scripts/db-manager.js migrate   # 执行迁移
 *   node scripts/db-manager.js reset     # 清空数据
 *   node scripts/db-manager.js repair    # 修复数据库
 */

// 1. 初始化：创建 tasks, videos, publish_records 表
// 2. 迁移：根据版本号执行对应的 SQL 迁移文件
// 3. 重置：TRUNCATE 所有表，保留结构
// 4. 修复：检查完整性，重建索引，清理孤立记录
```

  ```json
  "scripts": {
    "postinstall": "electron-rebuild -f -w better-sqlite3"
  }
  ```
- **验证**：better-sqlite3 v11.7.0 官方支持 Node 16.20.1+，完全兼容 Node 18.20.5

**2. FFmpeg 二进制文件**
- **问题**：@ffmpeg-installer/ffmpeg 需要下载对应平台的二进制文件
- **解决方案**：
  - 首次安装时自动下载（约 70MB）
  - 或使用系统已安装的 FFmpeg（通过环境变量配置）
- **验证**：跨平台支持（Windows/macOS/Linux）

**3. Playwright 浏览器下载**
- **问题**：首次安装需要下载 Chromium 浏览器（约 300MB）
- **解决方案**：
  ```bash
  npx playwright install chromium
  ```
- **验证**：Playwright 1.49.0 官方支持 Node 18+
