## 📡 端口监听规划

### 1. 端口分配表

从 **10030** 开始，按模块顺序分配端口号：

| 模块名称 | 端口号 | 用途 | 状态 |
|---------|--------|------|------|
| **主进程服务** | 10030 | 主进程 HTTP 服务（可选） | 保留 |
| **开发热更新** | 10031 | Vite Dev Server (渲染进程) | 开发环境 |
| **下载服务** | 10032 | 下载任务 WebSocket 服务（可选） | 保留 |
| **剪辑服务** | 10033 | 剪辑任务进度推送（可选） | 保留 |
| **导出服务** | 10034 | 导出任务状态服务（可选） | 保留 |
| **调试工具** | 10035 | DevTools 调试端口 | 开发环境 |
| **API 服务** | 10036 | 预留 REST API（MCP 集成） | 未来扩展 |
| **扩展服务** | 10037-10040 | 预留给未来新增模块 | 保留 |

### 2. 端口使用规范

#### 2.1 开发环境端口配置

**electron.vite.config.ts**
```typescript
import { defineConfig } from 'electron-vite'

export default defineConfig({
  main: {
    // 主进程配置
  },
  preload: {
    // 预加载脚本配置
  },
  renderer: {
    server: {
      port: 10031,  // 渲染进程开发服务器端口
      strictPort: true,  // 端口被占用时不自动尝试其他端口
    }
  }
})
```

#### 2.2 生产环境端口配置

生产环境通常不需要监听端口（Electron 本地应用），但如果需要提供本地 API 服务：

```typescript
// src/main/services/HttpServer.ts
const HTTP_SERVER_PORT = 10030;

const server = http.createServer(app);
server.listen(HTTP_SERVER_PORT, 'localhost', () => {
  console.log(`HTTP 服务已启动: http://localhost:${HTTP_SERVER_PORT}`);
});
```

#### 2.3 端口冲突检测

启动前检测端口是否被占用：

```typescript
import net from 'node:net';

async function isPortAvailable(port: number): Promise<boolean> {
  return new Promise((resolve) => {
    const server = net.createServer();
    server.once('error', (err: NodeJS.ErrnoException) => {
      if (err.code === 'EADDRINUSE') {
        resolve(false);
      }
    });
    server.once('listening', () => {
      server.close();
      resolve(true);
    });
    server.listen(port, 'localhost');
  });
}

// 使用示例
const port = 10030;
if (!(await isPortAvailable(port))) {
  console.error(`端口 ${port} 已被占用，请检查其他程序`);
  process.exit(1);
}
```

## 🔌 IPC 通信规范

### 1. 通信架构

```
┌─────────────────────────────────────────────────┐
│              渲染进程（Renderer）                  │
│                                                 │
│  ┌──────────────────────────────────────────┐  │
│  │  使用 window.api.xxx() 调用              │  │
│  │  通过 preload.ts 暴露的安全 API           │  │
│  └──────────────┬───────────────────────────┘  │
│                 │                               │
└─────────────────┼───────────────────────────────┘
                  │ (IPC 通信)
┌─────────────────┼───────────────────────────────┐
│                 ▼                               │
│  ┌──────────────────────────────────────────┐  │
│  │  preload.ts - contextBridge 暴露 API    │  │
│  └──────────────┬───────────────────────────┘  │
│                 │                               │
│              主进程（Main）                      │
│                 ▼                               │
│  ┌──────────────────────────────────────────┐  │
│  │  ipcMain.handle() / ipcMain.on()        │  │
│  │  处理业务逻辑并返回结果                    │  │
│  └──────────────────────────────────────────┘  │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 2. 通信协议命名规范

#### 2.1 命名格式

```
<模块名>:<操作类型>:<具体操作>
```

**示例：**
- `download:task:create` - 创建下载任务
- `edit:task:start` - 开始剪辑任务
- `export:file:compress` - 压缩导出文件

#### 2.2 模块名称定义

| 模块名 | 说明 | 前缀示例 |
|-------|------|---------|
| `download` | 下载模块 | download:* |
| `edit` | 剪辑模块 | edit:* |
| `export` | 导出模块 | export:* |
| `settings` | 设置模块 | settings:* |
| `database` | 数据库操作 | db:* |
| `file` | 文件操作 | file:* |
| `system` | 系统功能 | system:* |
| `window` | 窗口管理 | window:* |

#### 2.3 操作类型定义

| 操作类型 | 说明 | 示例 |
|---------|------|------|
| `task` | 任务相关 | download:task:create |
| `config` | 配置相关 | edit:config:get |
| `file` | 文件操作 | export:file:save |
| `query` | 查询操作 | db:query:tasks |
| `event` | 事件通知 | download:event:progress |

### 3. IPC 通信类型

#### 3.1 双向通信（invoke/handle）

**用于需要返回结果的操作**

**渲染进程调用：**
```typescript
// src/renderer/src/composables/useDownload.ts
async function createDownloadTask(url: string) {
  try {
    const result = await window.api.download.createTask(url);
    return result;
  } catch (error) {
    console.error('创建下载任务失败:', error);
    throw error;
  }
}
```

**主进程处理：**
```typescript
// src/main/ipc/download.ts
import { ipcMain } from 'electron';

ipcMain.handle('download:task:create', async (event, url: string) => {
  try {
    const task = await downloadService.createTask(url);
    return {
      success: true,
      data: task,
      message: '任务创建成功'
    };
  } catch (error) {
    return {
      success: false,
      error: error.message
    };
  }
});
```

**preload.ts 暴露：**
```typescript
// src/preload/index.ts
import { contextBridge, ipcRenderer } from 'electron';

contextBridge.exposeInMainWorld('api', {
  download: {
    createTask: (url: string) => ipcRenderer.invoke('download:task:create', url),
    cancelTask: (taskId: string) => ipcRenderer.invoke('download:task:cancel', taskId),
    getTaskList: () => ipcRenderer.invoke('download:task:list'),
  }
});
```

#### 3.2 单向通信（send/on）

**用于简单通知或不需要返回值的操作**

```typescript
// 渲染进程发送
window.api.system.notify('下载完成', '所有视频已下载完成');

// 主进程接收
ipcMain.on('system:notify', (event, title: string, message: string) => {
  // 显示系统通知
  new Notification({ title, body: message }).show();
});
```

#### 3.3 事件订阅（主进程 → 渲染进程）

**用于主进程主动推送事件到渲染进程**

**主进程发送：**
```typescript
// src/main/services/TaskManager.ts
import { BrowserWindow } from 'electron';

class TaskManager {
  notifyProgress(taskId: string, progress: number) {
    const mainWindow = BrowserWindow.getAllWindows()[0];
    mainWindow?.webContents.send('download:event:progress', {
      taskId,
      progress,
      timestamp: Date.now()
    });
  }
}
```

**渲染进程接收：**
```typescript
// src/renderer/src/composables/useDownload.ts
import { onMounted, onUnmounted } from 'vue';

function setupProgressListener() {
  const handler = (event: any, data: any) => {
    console.log(`任务 ${data.taskId} 进度: ${data.progress}%`);
    updateProgress(data.taskId, data.progress);
  };

  onMounted(() => {
    window.api.download.onProgress(handler);
  });

  onUnmounted(() => {
    window.api.download.offProgress(handler);
  });
}
```

**preload.ts 暴露：**
```typescript
// src/preload/index.ts
contextBridge.exposeInMainWorld('api', {
  download: {
    onProgress: (callback: Function) => {
      ipcRenderer.on('download:event:progress', callback);
    },
    offProgress: (callback: Function) => {
      ipcRenderer.removeListener('download:event:progress', callback);
    }
  }
});
```

### 4. IPC 通信消息格式

#### 4.1 请求格式（渲染进程 → 主进程）

```typescript
interface IpcRequest<T = any> {
  payload: T;           // 请求数据
  timestamp?: number;   // 时间戳（可选）
  requestId?: string;   // 请求ID（用于追踪）
}
```

**示例：**
```typescript
// 创建下载任务
const request: IpcRequest<{ url: string; options: object }> = {
  payload: {
    url: 'https://example.com/video.mp4',
    options: {
      autoEdit: true,
      proxy: ''
    }
  },
  timestamp: Date.now(),
  requestId: 'req-123456'
};
```

#### 4.2 响应格式（主进程 → 渲染进程）

```typescript
interface IpcResponse<T = any> {
  success: boolean;        // 是否成功
  data?: T;                // 返回数据（成功时）
  error?: string;          // 错误信息（失败时）
  code?: string;           // 错误码
  message?: string;        // 提示信息
  timestamp?: number;      // 时间戳
}
```

**示例：**
```typescript
// 成功响应
const successResponse: IpcResponse<Task> = {
  success: true,
  data: {
    id: 'task-001',
    url: 'https://example.com/video.mp4',
    status: 'pending'
  },
  message: '任务创建成功',
  timestamp: Date.now()
};

// 失败响应
const errorResponse: IpcResponse = {
  success: false,
  error: '链接格式不正确',
  code: 'INVALID_URL',
  timestamp: Date.now()
};
```

#### 4.3 事件通知格式（主进程 → 渲染进程）

```typescript
interface IpcEvent<T = any> {
  type: string;          // 事件类型
  payload: T;            // 事件数据
  timestamp: number;     // 时间戳
}
```

**示例：**
```typescript
// 下载进度事件
const progressEvent: IpcEvent<ProgressData> = {
  type: 'download:event:progress',
  payload: {
    taskId: 'task-001',
    progress: 45,
    downloaded: 45 * 1024 * 1024,  // 45MB
    total: 100 * 1024 * 1024        // 100MB
  },
  timestamp: Date.now()
};
```

## 📊 日志规范

### 1. 日志级别

| 级别 | 说明 | 使用场景 |
|------|------|---------|
| `error` | 错误 | 程序错误、异常情况 |
| `warn` | 警告 | 潜在问题、不推荐的操作 |
| `info` | 信息 | 重要业务流程、状态变更 |
| `debug` | 调试 | 详细调试信息（仅开发环境） |

### 2. 日志格式

```typescript
// src/main/utils/logger.util.ts
import winston from 'winston';

const logger = winston.createLogger({
  format: winston.format.combine(
    winston.format.timestamp({ format: 'YYYY-MM-DD HH:mm:ss' }),
    winston.format.printf(({ timestamp, level, message, module }) => {
      return `[${timestamp}] [${level.toUpperCase()}] [${module}] ${message}`;
    })
  ),
  transports: [
    new winston.transports.File({ 
      filename: 'logs/app.log',
      level: 'info'
    })
  ]
});

// 使用示例
logger.info('任务创建成功', { 
  module: 'download',
  taskId: 'task-001'
});
```
