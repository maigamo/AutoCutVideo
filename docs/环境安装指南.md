# AutoCutVideo 环境安装指南

> 本文档提供详细的开发环境安装步骤和精确的版本号

## 📋 安装前须知

### 系统要求

| 系统 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **Windows** | Windows 10 (64位) | Windows 11 (64位) |
| **macOS** | macOS 10.15+ | macOS 12+ |
| **Linux** | Ubuntu 20.04+ | Ubuntu 22.04+ |
| **内存** | 4GB | 8GB+ |
| **磁盘空间** | 10GB | 20GB+ |

### 版本兼容性说明

⚠️ **所有版本号都是经过测试的精确版本，请严格按照指定版本安装！**

本项目核心依赖关系：
```
Node.js 18.20.5
├─ Electron 32.2.7 (内置 Node.js 18.20.5)
├─ npm 10.8.2 (随 Node.js 18.20.5 安装)
└─ Python 3.12.x (用于编译原生模块)
```

## 🔧 安装步骤

### 步骤 1：安装 Node.js

#### Windows 系统

**方法1：使用官方安装包（推荐）**

1. 下载 Node.js 18.20.5：
   ```
   https://nodejs.org/dist/v18.20.5/node-v18.20.5-x64.msi
   ```

2. 双击运行安装程序
   - 接受许可协议
   - 选择安装路径（建议默认：`C:\Program Files\nodejs\`）
   - 勾选"Add to PATH"
   - 点击"Install"

3. 验证安装：
   ```powershell
   node -v
   # 应该输出：v18.20.5
   
   npm -v
   # 应该输出：10.8.2
   ```

**方法2：使用 Chocolatey**

```powershell
# 以管理员身份运行 PowerShell
choco install nodejs-lts --version=18.20.5 -y
```

#### macOS 系统

**方法1：使用官方安装包（推荐）**

1. 下载 Node.js 18.20.5：
   ```
   https://nodejs.org/dist/v18.20.5/node-v18.20.5.pkg
   ```

2. 双击运行安装程序并按提示完成安装

3. 验证安装：
   ```bash
   node -v
   # 应该输出：v18.20.5
   
   npm -v
   # 应该输出：10.8.2
   ```

**方法2：使用 Homebrew**

```bash
# 安装特定版本的 Node.js
brew install node@18

# 链接到系统
brew link node@18

# 验证版本
node -v
```

#### Linux 系统（Ubuntu/Debian）

**使用 NodeSource 仓库（推荐）**

```bash
# 更新系统
sudo apt update

# 安装必要工具
sudo apt install -y curl

# 添加 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -

# 安装 Node.js 18.x
sudo apt install -y nodejs

# 验证安装
node -v
# 应该输出：v18.20.5 (或 18.x 最新版)

npm -v
# 应该输出：10.x
```

### 步骤 2：安装 Git

#### Windows

1. 下载 Git for Windows：
   ```
   https://git-scm.com/download/win
   ```

2. 双击运行安装程序

   ```powershell

   ```

```bash
# 使用 Homebrew 安装

# 验证
```

#### Linux

```bash
sudo apt install -y git

# 验证
git --version
```

### 步骤 4：安装 FFmpeg

#### Windows

**方法1：使用 Chocolatey（推荐）**

```powershell
# 以管理员身份运行
choco install ffmpeg -y
```

**方法2：手动安装**

1. 下载 FFmpeg：
   ```
   https://www.gyan.dev/ffmpeg/builds/
   ```
   下载 `ffmpeg-release-full.7z`

2. 解压到 `C:\ffmpeg`

3. 添加到系统PATH：
   - 右键"此电脑" → "属性"
   - "高级系统设置" → "环境变量"
   - 在"系统变量"中找到"Path"，点击"编辑"
   - 添加：`C:\ffmpeg\bin`

4. 验证安装：
   ```powershell
   ffmpeg -version
   # 应该输出 FFmpeg 版本信息
   ```

#### macOS

```bash
brew install ffmpeg

# 验证
ffmpeg -version
```

#### Linux

```bash
sudo apt install -y ffmpeg

# 验证
ffmpeg -version
```

### 步骤 5：安装项目依赖

#### 1. 克隆项目

```bash
# 克隆项目仓库

cd AutoCutVideo-dev
```

#### 2. 配置 npm（可选，提高下载速度）

```bash

# 配置 Electron 镜像

# 配置 Playwright 镜像

```

#### 3. 安装项目依赖

```bash
# 安装所有依赖（这可能需要5-10分钟）

```

```
123 packages are looking for funding
  run `npm fund` for details

found 0 vulnerabilities
```

#### 4. 编译原生模块

```bash
# 为 Electron 重新编译 better-sqlite3
npm run rebuild
```

**预期输出：**
```
✔ Rebuild Complete
```

## 🔍 常见问题排查

### 问题1：`npm install` 失败

**可能原因：**
- 网络问题
- 权限问题
- Node.js 版本不对

**解决方案：**

```bash
# 1. 清理缓存
npm cache clean --force

# 2. 删除 node_modules 和 package-lock.json
rm -rf node_modules package-lock.json  # macOS/Linux
rmdir /s /q node_modules && del package-lock.json  # Windows

# 3. 重新安装
npm install
```

### 问题2：`better-sqlite3` 编译失败

**可能原因：**
- 缺少 Python
- 缺少构建工具

**解决方案：**

**Windows：**
```powershell
# 安装 Windows 构建工具
npm install --global windows-build-tools

# 或者安装 Visual Studio Build Tools
# 下载地址：https://visualstudio.microsoft.com/downloads/
# 选择 "Desktop development with C++"
```

**macOS：**
```bash
# 安装 Xcode Command Line Tools
xcode-select --install
```

**Linux：**
```bash
# 安装构建工具
sudo apt install -y build-essential
```

### 问题3：Playwright 浏览器下载失败

**解决方案：**

```bash
# 手动安装 Chromium
npx playwright install chromium

# 如果国内网络问题，使用镜像
PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/ npx playwright install chromium
```

### 问题4：FFmpeg 找不到

**解决方案：**

```bash
# 验证 FFmpeg 是否在 PATH 中
where ffmpeg  # Windows
which ffmpeg  # macOS/Linux

# 如果找不到，重新添加到 PATH 或重新安装
```

### 问题5：Node.js 版本不对

**解决方案：**

使用 nvm（Node Version Manager）管理多个 Node.js 版本：

**Windows (nvm-windows)：**
```powershell
# 安装 nvm-windows
# 下载地址：https://github.com/coreybutler/nvm-windows/releases

# 安装 Node.js 18.20.5
nvm install 18.20.5

# 使用该版本
nvm use 18.20.5
```

**macOS/Linux (nvm)：**
```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 重启终端，然后：
nvm install 18.20.5
nvm use 18.20.5
```
